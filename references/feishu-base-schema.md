# 飞书多维表格「剪辑组数据中台」建表结构

一次性初始化时创建一个飞书多维表格 Base，命名为 **剪辑组数据中台**，包含以下 7 张表。
用 lark-base 技能创建；用户对云文档只有查看权限、未明确授权时，不得擅自写入或修改任何线上表，
先把建表方案发给用户确认后再执行。

字段类型说明：文本、单选、多选、数字、日期、链接（超链接/URL）。

## 本地配置 config.json（默认会话直出、飞书可选）

位于 `D:\豆包工作区\config.json`，是整套流程的解耦中枢；不写死任何飞书链接。关键字段：

- `delivery.mode`：`direct_to_chat`（默认，结果直接在会话发送，含视频/Excel/报告）；`also_archive_local` 控制是否同时本地留档；`send_to_feishu_group` 默认 false。
- `feishu.enabled`：默认 false；团队建好表后，把链接填到 `feishu.base_url` 并置 true，子技能才写飞书。
- `workspace`：各子目录相对路径。
- `cost`：`default_date`、`naming_rule`、`attribution_regex`、`tolerance_pct`（合计校验阈值，默认 1.0）、`editor_code_map`（剪辑师代号→姓名）。
- `platforms[]`：有米有数、巨量引擎、腾讯广告、磁力引擎、百度营销，各含 `code/url/enabled/logged_in`。
- `accounts[]`：每个投放账户 `{platform, account_id, name, backend_url}`。
- `safety`：广告后台只读、不绕风控、遇扫码暂停、不自动安装软件等开关。

> 用户说"以后数据用这个飞书表：<链接>"时：更新 `feishu.base_url` 与 `feishu.enabled=true` 即可，无需改任何 SKILL.md。
