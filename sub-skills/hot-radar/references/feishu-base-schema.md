# 飞书多维表格结构（Base「剪辑组数据中台」）

本技能只与「竞品清单」「爆款库」两张表交互；其它表（素材登记表、预审记录、消耗明细、运维表、剪辑师名单）由其它技能维护。
**首次运行先核对表是否已存在、字段是否一致**；缺失时向用户说明需要建哪些字段，不擅自改动用户未授权的云文档。

## 表1：竞品清单
用于把"本品 → 别名 → 关联对标账号"固化，抓取时自动扩展检索词。

| 字段名 | 类型 | 说明 |
|---|---|---|
| 本品名称 | 文本（主键） | 如 紫苏籽油 |
| 别名/关键词 | 多选或文本 | 陆地鱼油、草本液体黄金、辅食油 等 |
| 品类 | 单选 | 食品饮料 / 个护养 / 其他 |
| 对标账号 | 文本 | 账号名 |
| 账号平台 | 单选 | 抖音 / 快手 / 视频号 |
| 账号主页链接 | URL | 主页或分享链接 |
| 账号ID/sec_uid | 文本 | 抖音 sec_uid、快手 user_id 等 |
| 备注 | 文本 | 采集注意点 |

## 表2：爆款库
每条视频/素材一行。**唯一键 = 平台 + 视频ID（或素材ID）**。

| 字段名 | 类型 | 说明 |
|---|---|---|
| 视频编号 | 文本（主键） | 报告内编号 V01…；建议 `平台-视频ID` |
| 平台 | 单选 | 抖音 / 快手 / 视频号 / 百度 / 有米有数 |
| 来源 | 单选 | 有米有数 / 平台网页 / 账号主页 |
| 视频ID/素材ID | 文本 | 抖音 aweme_id、快手作品id、有米有数素材ID |
| 账号/广告主 | 文本 | 自然流量为账号名；广告为广告主 |
| 标题/口播首句 | 文本 | 便于检索 |
| 链接 | URL | 播放页或素材页 |
| 关联商品 | 文本 | 有米有数广告素材必填 |
| 发布时间 | 日期 | 拿不到留空 |
| 首次发现日期 | 日期 | 有米有数字段 |
| 投放天数 | 数字 | 仅广告素材，第三方估算需注明 |
| 时长(秒) | 数字 | |
| 点赞 | 数字 | 三平台口径不一致时在备注注明 |
| 评论 | 数字 | |
| 转发/分享 | 数字 | |
| 互动数 | 数字 | 平台只给综合互动时用 |
| 下载路径 | 文本 | 本地 mp4 路径 |
| 钩子类型 | 单选 | 痛点提问/结果前置/反差冲突/利益福利/悬念留白/身份点名/热点借势/权威背书/产品特写冲击/剧情冲突 |
| 主卖点 | 文本 | |
| 拍摄形式 | 单选 | 口播/剧情/实拍/混剪/AI |
| 分析文档链接 | URL | 回填飞书文档链接 |
| 需修复 | 复选框 | 供「素材修复与溯源」技能读取 |
| 需溯源 | 复选框 | 同上 |
| 修复状态 | 单选 | 待处理/已修复/无需修复 |
| 修复后路径 | 文本 | 技能B 回填 |
| 溯源状态 | 单选 | 待溯源/待人工确认/已确认 |
| 疑似原创 | 文本 | 账号+链接+置信度 |
| 授权状态 | 单选 | 未授权/沟通中/已授权 |
| 入库日期 | 日期 | 首次写入日期 |
| 数据更新时间 | 日期 | 增量模式仅更新互动数据时刷新 |
| 备注 | 文本 | 口径、估算来源、未获取项 |

## 增量模式逻辑
- 抓取后以「平台 + 视频ID/素材ID」在「爆款库」查重。
- 新记录：下载 + 拆解 + 写入全字段。
- 已存在：仅更新点赞/评论/转发/投放天数与「数据更新时间」，不重复下载、不重复分析。

## 飞书文档《产品卖点库》
- 查找本品：产品名、核心卖点（成分/含量/工艺/产地/价格）、目标人群、合规可用表述、禁用表述。
- 找不到本品条目：暂停做开头，向用户索要本品名称与卖点，不臆造。
