# 素材预审（违禁词 / 违规风险 / 技术规格 / 制作瑕疵）

给待投放或待发布的短视频做上线前体检：把口播、画面字幕、标题文案里的违规表述找出来，同时检查技术规格与制作瑕疵，
给出风险等级、规则依据和可直接落地的改法。

## 交付方式（默认会话直出，不绑飞书）
- 预审报告**直接在会话里发给用户**；用户给了目录就存给的目录，没给则用 `D:\豆包工作区\05_预审报告\`。
- 不默认写飞书；用户提供了预审记录表/文档并授权时才写入。

## 输入与开工确认

- 输入：① 视频文件（或抖音/快手/百度链接）；② 纯口播/脚本文本；③ 标题+封面文案。
- 确认投放**平台**与**产品类目**：默认抖音、快手、百度都给通用结论；
  类目默认按"普通食品"（如食用油/农产品），若是保健食品、医疗器械、化妆品等要明确，因为功效宣称边界不同。
- 用户给了自己的《素材预审规则库》《产品资质》等文档，优先读取并以其规则为准；没有就按通用广告法与各平台公开规范判断，并在报告里注明"本次按通用规范审核，未接入你方专属规则库，请结合自身规则复核"。
- 若给的是视频链接，先用 `hot-clip-repair` 技能第 1 步的平台方法下载，再处理。

## 总流程

### 第 1 步：把"会被审核看到的文案"全部抽出来

优先加载 `byted-mediakit-video`：

- 口播：`asr-subtitles`（带时间戳）→ `asr.txt`。
- 画面文字（字幕、贴纸、标题、角标）：`video-ocr`（带时间戳）→ `ocr.txt`。
- 用户提供的标题/封面/详情文案：另存 `title.txt`。
- 纯文本输入直接作为文本源。
- **降级**：ASR/OCR 工具不可用时，基于能读到的画面/字幕/用户提供脚本审查，并在报告里列出"未能提取口播/OCR"等局限，不假装完整看过；纯文本输入只审文本并说明范围。

### 第 2 步：确定性词库扫描（脚本）

用 `scripts/scan_words.py` 对文本逐个扫描，词库在 `assets/wordlib.json`：

```bash
python scripts/scan_words.py asr.txt --source 口播 --lib assets/wordlib.json -o 命中_口播.md
python scripts/scan_words.py ocr.txt --source 画面字幕 --lib assets/wordlib.json -o 命中_画面.md
```

- 精确匹配（含常见空格/标点容忍），输出命中词、类别、风险等级、所在句子、时间点（若有）。
- 可一次传多个文件：`scan_words.py asr.txt ocr.txt title.txt --lib ...`。
- 词库覆盖：广告法绝对化用语、虚假/夸大宣传、食品功效与医疗禁忌、资质类宣称（有机/地标/无添加/特供）、导流与价格欺诈、平台敏感词。
- **降级（词库/脚本缺失）**：无法运行 `scan_words.py` 或 `wordlib.json` 时，降级为模型逐条语义审查，并在报告开头明确"本次未跑确定性词库扫描、可能漏判，建议补齐后复检"；**不得用模型结果冒充词库命中**。

### 第 3 步：AI 语义复核（脚本扫不出的部分）

确定性扫描只能命中字面词，再由模型通读全部文本，补查：

- **隐含/擦边功效**：没说"治疗"但暗示治病（如"血压稳了""血糖不高了""吃了就不咳了"）、暗示减肥/壮阳/益智/抗癌/提高免疫力。
- **谐音/拆字/符号变体**：如"最 好""第1""特效→特xiao""神*效"等规避写法。
- **绝对化的同义表达**、无依据的销量第一/销量冠军、虚假"原价/限时/最后一天"。
- **不当背书**：医生/专家/患者名义、机构/国家/军队名义、绝对安全性承诺。
- **前后矛盾或误导**：口播与画面/标题不一致，普通食品摆出"蓝帽子"或药盒暗示。
- 判断依据见 `references/rules.md`，逐条给出"原句 → 风险 → 为什么 → 建议改法"。

### 第 4 步：技术规格与制作瑕疵（不依赖词库）
- 能读参数（ffprobe/工具）：分辨率、画幅（竖版常见 9:16）、时长、码率、帧率、音量是否符合目标平台常见投放规格。
- 画面/声音瑕疵：黑边、明显模糊、爆音/削波、黑屏/跳帧/卡顿、错别字、字幕与口播不一致、字幕遮挡主体。
- 版权/肖像：BGM 是否可能未授权、是否含他人画面/影视综艺片段、字体商用授权、是否出现可识别名人肖像、是否有未成年人出镜。
- 读不了参数就描述明显瑕疵，不编造数值；授权状态无法核验的，统一进"需人工确认"清单。

### 第 5 步：平台差异提示
- 三平台共同红线：广告法、食品/医疗功效、绝对化用语、虚假承诺。
- 平台特有口径（抖音巨量、快手磁力、百度营销）见 `references/rules.md` 末尾，对命中项标注"哪些平台一定驳回 / 哪些限制投放"。

### 第 6 步：输出预审报告

`素材预审报告_<素材名>.md`，结构见 `references/rules.md` 模板，至少包含：

1. 总评：可直接过 / 需修改后过 / 高风险不建议投。
2. 命中明细表：来源（口播/画面/标题）、时间点、原文、风险词、类别、风险等级、依据、修改建议（给可替换的具体说法）。
3. 高风险项置顶（必须改），中风险建议改，低风险提示。
4. 可直接替换的安全话术示例（把功效宣称改成合规的产品属性/食用场景描述）。
5. 技术规格与制作瑕疵清单。
6. **需人工确认清单**：肖像授权、未成年人出镜、BGM/字体商用授权等无法核验项——**只要存在这些项，不得判"通过"**。
7. 报告末尾固定一句：**本报告为投放前自查参考，不代表平台官方审核结果，最终以平台机审+人工审核为准。**

## 强制规则
- 食品（尤其普通食品）默认禁止任何疾病预防、治疗、保健功效宣称；普通食品提"提高免疫力/降三高/益智"等高风险功效，按高风险处理。
- 只做合规自查，不帮用户编造资质、认证、检测报告；"有机/蓝帽子/地标/无添加"等需用户提供真实凭证，没有就提示不能说。
- 报告必须能定位到具体句子与时间点，不要只写"有风险"；改法要可直接落地。
- 肖像授权、未成年人出镜、BGM/字体商用授权等无法核验项，一律标"需人工确认"，**绝不能为了给"通过"结论而忽略**。
- 不确定是否违规的，宁可列为中风险提示并说明，不轻易放行。
- 平台审核规则会更新，重大投放前建议用户用平台官方审核工具/预审通道二次确认（见 rules.md）。

## 参考文件
- `assets/wordlib.json`：违禁/风险词库（分类别、风险等级、依据、修改建议）。
- `references/rules.md`：规则要点、食品功效边界、各平台口径、语义复核清单与报告模板。
- `scripts/scan_words.py`：确定性扫描脚本，输出命中清单。
