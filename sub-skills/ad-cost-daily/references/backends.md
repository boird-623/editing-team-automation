# 四个广告后台导出、字段映射与归属校验

> 后台菜单会改版，下列入口与列名为常见基线；**以登录后实际页面为准**，字段对不上时按含义匹配，不要硬套列名。全程只读，只导出，不改任何设置。

## 一、四个后台（平台代码固定）
| 平台 | 后台 | 平台代码 | 报表位置（常见） |
|---|---|---|---|
| 抖音 | 巨量引擎 | `douyin` | 数据/报表 → 素材（创意）维度 → 自定义列 → 导出 |
| 视频号 | 腾讯广告 | `tencent` | 报表 → 素材/广告维度 → 字段选择 → 导出 |
| 快手 | 磁力引擎 | `kuaishou` | 数据报表 → 素材分析 → 自定义指标 → 导出 |
| 百度 | 百度营销 | `baidu` | 报告 → 创意/素材报告 → 自定义列 → 下载 |

导出文件统一命名：`{平台代码}_{账户ID}.xlsx`，存放 `06_报表导出\{日期}\`。

## 二、统一字段（parse_cost.py 输出口径）
统一列名（英文）：
`date, platform, account_id, material_id, material_name, cost, impressions, clicks, conversions, play_3s_rate, editor_code, editor_name`

- `cost`：消耗，**元**（数值型）。
- `impressions`：展示/曝光；`clicks`：点击；`conversions`：转化数。
- `play_3s_rate`：3秒播放率，**小数**（0.63，不是 63%）。

各后台列名别名（命中其一即可，可在脚本 COLUMN_MAP 增补）：
| 统一字段 | 常见列名 |
|---|---|
| material_id | 素材ID / 创意ID / 素材编号 / 创意编号 |
| material_name | 素材名 / 素材名称 / 创意名称 / 素材 |
| cost | 消耗 / 花费 / 总消耗 / 消耗金额 / 费用 |
| impressions | 展示 / 展现 / 曝光 / 展示量 / 展现量 |
| clicks | 点击 / 点击量 / 点击数 |
| conversions | 转化 / 转化数 / 转化量 / 成交 / 目标转化数 |
| play_3s_rate | 3秒播放率 / 3s播放率 / 3秒播放比例 |

## 三、数值清洗
- 去掉千分位逗号、货币符号、空格。
- 带单位换算：`1.2万`→12000；`1,234.5`→1234.5；`元`保留。
- 百分比：`63.2%`→0.632；纯百分数 `63` 若列名含"率"按 /100 处理。
- 空值/`-`/`--` 记为 0 或空（消耗按 0，率类留空）。
- 消耗一律人民币元；若某账户币种不同，停止并在运维表标注，不擅自换算。

## 四、素材归属（优先级从上到下）
1. 素材名正则：
   `^(\d{6})_([A-Z]{2,4})_(.+?)_(KB|JQ|HJ|SP|AI)_(S\d+)_(V\d+)`
   - 第1组日期 `YYMMDD`，**第2组剪辑师代号**（2-4 位大写字母），第3组产品，第4组类型，第5组脚本号，第6组版本。
   - 代号→姓名查「剪辑师名单」。
2. 解析失败：用 `material_id` 查「素材登记表」反查剪辑师。
3. 仍失败：`editor_name = 未归属`，进日报未归属清单并 @投手认领。

## 五、写入唯一键与回刷
- 唯一键：`date + platform + account_id + material_id`。
- 已存在则**整行覆盖**（平台会回刷数据，以最新导出为准）；不做增量累加。
- 同一素材在多账户/多平台重复出现时，按唯一键各自保留，排行按 material_id 汇总。

## 六、合计校验
- 每个平台：汇总本次写入明细的 cost 合计 = `sum_detail`。
- 与后台账户总消耗（页面显示或账户汇总行）`sum_backend` 比对：
  `差异率 = abs(sum_detail - sum_backend) / sum_backend`。
- 差异率 > **1%**：在「运维表」写告警（平台、账户、日期、两个合计、差异率），日报标注，不抹平。
- 常见原因：时区/日期口径、素材维度被聚合或过滤、其他非素材消耗、导出未完成。

## 七、起量与衰退（阈值以《消耗指标口径》为准）
- 脚本只给排序和候选；**是否起量/衰退按飞书《消耗指标口径》的阈值**判定，不硬编码。
- 常见参考（需口径确认后启用）：新起量=近 N 日消耗快速上升且达到阈值；衰退=消耗/点击率/3秒播放率连续 N 日下滑。
- 日报：新起量前5、衰退清单、未归属清单。
- 周报：人均消耗趋势、爆款率（达到起量阈值素材/在投素材）、平均生命周期（首日起量到衰退日）。

## 八、parse_cost.py 用法
```
python parse_cost.py <06_报表导出/日期 目录> --date 2026-10-13 \
    [--editors 剪辑师名单.xlsx] [--register 素材登记表.xlsx] \
    [--backend-totals totals.json] -o 明细_2026-10-13.xlsx
```
- 自动扫描目录下 `{平台}_{账户}.xlsx`，按文件名识别 platform/account。
- 输出：统一明细（含归属）、平台合计校验、未归属清单（stdout 汇总 JSON）。
- `--backend-totals` 可选：后台账户总消耗 JSON `{douyin:{账户:合计},...}`，用于合计校验。
